# AI Agent Homework 1

## 作業方向
英文單字小老師

## 實作內容
本作業從 `1.4-openai-api-with-memory` 分支開始實作。

我修改了 `main.js` 中 `initMessage()` 的系統指令，
將原本的聊天機器人改成「英文單字小老師」。

角色功能包含：

- 使用繁體中文解釋英文單字
- 說明單字意思與詞性
- 提供常見用法
- 提供簡單的英文例句
- 根據使用者的英文程度調整回答
- 記住前面對話中提到的資訊

## 測試結果

### 第 1 輪
**User：**
我的英文程度大概是多益 500 分左右，我想學工作上常用的單字。

### 第 2 輪
**User：**
請教我 deadline。

### 第 3 輪
**User：**
那 schedule 呢？

### 第 4 輪
**User：**
可以用剛才那兩個單字各造一個適合我程度的句子嗎？

### 第 5 輪
**User：**
我剛才說我的英文程度大概是多少？我想學哪一類的單字？

**Assistant：**
你剛才說你的英文程度大約是 **多益 500 分左右**，而且想學習 **工作上常用的英文單字**。

## 測試結論
聊天機器人能進行 5 輪以上的對話，並能正確記住先前對話中提到的英文程度與學習需求，代表對話記憶功能正常運作。
